# Coffee and autumn shapes

Editable artwork and generator for the `cup`, `mug`, `takeaway` (set
`container`) and `coffeebean`, `pumpkin`, `jackolantern` (set `food`) shapes
introduced in ggfoundry 0.4.0.

- `source-svg/`: twelve editable black source SVGs, two per symbol.
- `make_shapes.py`: original vector geometry. Run `python3 make_shapes.py`
  (needs `rsvg-convert`) to regenerate the source SVGs and write the converted
  Cairo SVGs directly to `inst/extdata/`. It only writes the twelve paired
  files for these six shapes and never touches other assets, including the
  bowls (generated by `data-raw/porridge/`) and the iCloud artwork handled by
  `../DATASET.R`.
- `preview-svg/` is not recreated here; use the prototype folder's previews
  for visual review. All paired assets share a 200 x 200 canvas: never crop
  an outline or fill file independently.
